یکی از مفید ترین کارهایی که با ابسیدین انجام میدم ساخت **گزارش عملکرد شخصی** است. این گزارش به من کمک می‌کنه اشراف کاملی نسبت به فعالیت های خودم داشته باشم و با اختیار داشتن جزئیات بتونم عملکرد خودم رو دقیق تر ارزیابی کنم.

نمونه این گزارش‌ها رو می‌تونید در [[reports|📋گزارش‌های شخصی]] ببینید.

اگه می‌خواید از این روش استفاده کنید، توی این یادداشت کامل توضیح دادم تا چه طور از این مدل گزارش ها بسازید.

<br>

## گام اول: وارد کردن اطلاعات
در مرحله اول باید اطلاعات‌تون رو وارد کنید. گزارش‌های من معمولا دو بخش دارن. بخش اول **محتواهایی که مصرف کردم**. مثل کتاب، پادکست، دوره، فیلم و سریال. بخش دوم **ردیابی عادت‌های روزمره**. مثل ورزش، مطالعه و سوشال مدیا.

این دو مورد رو تو یادداشت‌های مستقل توضیح دادم:

```base
views:
  - type: cards
    name: view
    filters:
      and:
        - or:
            - file.name == "habit-tracker-in-obsidian"
            - file.name == "add-content-obsidian"
    sort:
      - property: file.name
        direction: DESC
    image: note.image
    cardSize: 200
```


برای اینکه این آموزش راحت تر باشه من روی همون تمپلیت هبیت ترکر توضیح میدم که پلاگین ها از قبل نصب و تنظیم شدند. پس:
1. این [ریپازیتوری](https://github.com/fardm/Obsidian-Habit-Tracker) رو دانلود کنید و با ابسیدین باز کنید.
2. عادت‌ها و محتواهاتون رو وارد کنید.
3. برای تفکیک فایل‌ها از تگ استفاده کنید. مثلا فایل های من اینطوری میشه:
```
#Journal

Resources
├── #Books
├── #Podcast
├── #Movies
└── #Media
```
4. به تنظیمات پلاگین پرشین کلندر برید. تمپلیت سالیانه رو روی `Yearly + Report` بذارید.
5. روی عدد امسال در تقویم پرشین کلندر کلیک کنید تا فایل سالیانه ساخته بشه.

تمام! حالا یه فایل داریم که گزارش عملکرد ما رو در امسال نشون میده.

<br>

## گام دوم: شخصی سازی تمپلیت
این تمپلیت سه تا بخش داره که میتونید هر کدوم رو ویرایش کنید:

### بخش در یک نگاه
این بخش با پلاگین dataview ساخته شده. این دستور برای استخراج آمار کتاب هست:
````
```dataview
TABLE WITHOUT ID
	length(rows) + " جلد کتاب" as count,  // تعداد کل کتاب ها رو محاسبه میکنه
	sum(rows.pages) + " صفحه" as sum // تمام پراپرتی های pages رو جمع میزنه
FROM #Book  // مشخص میکنه اطلاعات از تگ book استخراج بشن
WHERE date >= date("2025-03-21") AND date <= date("2026-03-20") // بازه زمانی رو مشخص میکنه
GROUP BY "" // همه اطلاعات رو توی یک ردیف نمایش میده
```
````

- از بخش FROM تگی که استفاده کردید رو وارد کنید. اگر برای کتاب ها از تگ Book استفاده کردید همین دستور براتون کار میکنه. اگر از تگ دیگه ای استفاده کردید اون رو جایگزین کنید.
- از بخش WHERE تاریخ شروع و پایان رو باید وارد کنید تا فقط گزارش یکسال مشخص رو نمایش بده نه همه کتاب هایی که خوندید.
- دستور `sum(rows.pages)` هم همه پراپرتی های pages رو جمع میزنه. من توی این پراپرتی تعداد صفحات کتاب ها رو نوشتم. اگر از عنوان دیگه ای برای تعداد صفحات استفاده کردید اون رو جایگزین کنید.

ساختار باقی موارد هم مثل همینه. فقط برای فیلم مقدار مدت زمان رو جمع میزنه.

<br>

### بخش محتواها
این بخش با پلاگین base ساخته شده. تنظیماتش بسیار ساده است. توی همون رابط کاربری میتونید ادیتش کنید.
از منوی Filter می تونید نمایش فایل ها رو محود کنید. یک تگ خاص مثلا Book رو فیلتر میکنیم. تاریخ رو هم بین بازه یکسال مشخص تنظیم میکنیم. 

از بخش  Properties هم میتونید محتویات کارت رو مشخص کنید که چه مواردی رو نمایش بده.

<br>

### بخش عادت‌ها
این بخش با سه پلاگین دیتاویو، ترکر و کانتریببوشن گراف ساخته شده. شخصی سازی این مورد رو کامل داخل ویدئوی [[habit-tracker-in-obsidian|ساخت هبیت ترکر در ابسیدین]] توضیح دادم.
