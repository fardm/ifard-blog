مارک داون(Markdown) یک زبان نشانه‌گذاری برای ساختار دادن به متن است که امروزه بسیاری از توسعه‌دهندگان و وبلاگ‌نویسان از آن استفاده می‌کنند. مارک داون یک زبان برنامه‌نویسی نیست، درواقع یک سیستم نشانه‌گذاری است که نمادها و علامت‌ها وقتی به ترتیب خاصی قرار بگیرند معانی مختلفی را به وجود می آورند.

## سینتکس‌های Markdown

### ۱. سرفصل‌ها (Headings)
برای ایجاد سرفصل کافیست ابتدای عنوان `#` را تایپ کنید و اسپیس بزنید. تعداد `#` رتبه عنوان را مشخص می کند.
- `# عنوان یک`
- `## عنوان دو`
- `### عنوان سه`
- `#### عنوان چهار`
- `##### عنوان پنج`
- `###### عنوان شش`

<br>

### ۲. تگ‌ها (tags)
برای ایجاد تگ علامت `#` را قبل از کلمه (بدون اسپیس) تایپ کنید. به این صورت: `#کلمه_کلیدی`

<br>

### ۳. لیست‌ها
برای ایجاد بولت پوینت قبل از متن یک خط تیره `-` تایپ کنید و اسپیس بزنید.
```
- مورد یک
- مورد دو
- مورد سه
```

<br>

برای لیست های عددی هم یک عدد به همراه نقطه `1.` تایپ کنید و اسپیس بزنید.
```
1. مورد یک
2. مورد دو
3. مورد سه
```

<br>

در مارک داون می‌توانید لیست تسک هم ایجاد کنید. با خط تیره و براکت با فضای خالی، تسک انجام نشده ایجاد می‌شود: `- [ ]`. برای علامت گذاری به عنوان انجام شده باید در براکت علامت × را بگذارید: `- [×]`.

- [ ] انجام نشده: `- [ ]`
- [x] انجام شده: `- [×]`

<br>

### ۴. استایل متن
از دستورات زیر می‌توانید برای تغییر استایل متن استفاده کنید:

- متن **بولد**: `**متن**`
- متن *کج*: `*متن*`
- متن ==هایلایت== شده: `==متن==`
- متن ~~خط خورده~~ : `~~متن~~`

<br>

### ۶. بلوک نقل قول
با اضافه کردن نماد `>` قبل متن می‌توانید بلوک نقل قول بسازید.

> لورم ایپسوم متن ساختگی با تولید سادگی نامفهوم از صنعت چاپ و با استفاده از طراحان گرافیک است.

<br>

### ۷. جدول
جدول در مارکدان به این صورت ایجاد می شود:
```md
|     |     |     |
| --- | --- | --- |
|     |     |     |
|     |     |     |
```

ردیف ها در هر سطر قرار می گیرند و ستون ها با خط عمودی ( | )  از هم جدا می‌شوند.

<br>

### ۸. کد
بلوک کد(Code Block) با سه تا بک تیک  ساخته می‌شود:
````html
‌```
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Document</title>
</head>
<body>
    
</body>
</html>
```
````

کد درون خطی(Inline Code) هم با یک بک تیک ساخته می‌شود:
```
`console.log()`
```

<br>

### ۹. هایپر لینک
هیاپر لینک با این ساختار ساخته می‌شود:
`[متن لینک](آدرس لینک)`

<br>

### ۱۰. پاورقی
پاورقی با براکت و علامت توان ایجاد می‌شود: `[^1]`
روش کار به این صورت است که این عبارت را در متن قرار می‌دهید سپس در انتهای سند همان عدد را دوباره ابتدای سطر می‌نویسید و متن خود را می‌نویسید. 


```md
جمله‌ای که در متن قرار دارد.[^1]


[^1]: این متن پاورقی است.

```

<br>

### ۱۱. تصاویر
برای نمایش تصاویر از این ساختار استفاده کنید: `![اسم دلخواه](لینک تصویر)`

<br>

### ۱۲. فاصله بین سطرها
فاصله‌هایی که بین سطرها با اینتر ایجاد می‌کنید در خروجی فایل تاثیری ندارند و به عنوان فضای خالی شناخته می‌شوند. برای ایجاد فاصله واقعی باید از عبارت `<br>` استفاده کنید. هر `<br>` یک سطر فاصله ایجاد می‌کند.
